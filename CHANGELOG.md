# Изменения

## 2.0.0

### Новое
- Проверка каждого сервера мимо туннеля: DoH-резолв, TCP и TLS через физический интерфейс (`vpn servers`).
- Обнаружение обхода VPN: состояние `LEAK`, когда балансировщик Happ ушёл в `fallbackTag: DIRECT`.
- Проверка раздельной маршрутизации на эталонных сайтах и по журналу Xray (`vpn routes`).
- Страна и владелец сети для IP в журнале через DNS Team Cymru, с кэшем на диске.
- Импорт JSON-конфига Happ (`vpn config`).
- Автопочинка с советами: после неудачного перезапуска сторож проверяет серверы и пишет, что делать.
- `vpn watch --keep-on`: включает туннель, если его выключили.
- Новая панель в стиле btop: графики задержки и трафика, панели серверов, маршрутов и соединений.
- `vpn doctor` показывает серверы, маршруты и список действий.
- Установщик одной командой, вывод без цветов в пайп и файл.

### Изменено
- Shebang `/usr/bin/env -S python3 -I`: работает с системным Python 3.9+ и с Homebrew.

## 1.0.0

- Сторож Happ: проверка по уровням, перезапуск туннеля, журнал, отчёт, замер скорости, живая панель.
